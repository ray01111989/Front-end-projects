# My Hometown

A static web page about my hometown, As-Suwayda in southern Syria: a short introduction and photos and links for a few of its best-known places, such as Salkhad Castle, Shahba, and the Temple of the Sun God.

## Use it

Open `index.html` in a browser. No install is needed.

## Files

```
index.html   Page content
styles.css   Styles
images/      Photos used on the page
```
