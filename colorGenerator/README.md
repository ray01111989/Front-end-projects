# Color Scheme Generator

Pick a color, choose a scheme type (monochrome, analogic, complement, triad, quad, and more), and get a matching palette from [The Color API](https://www.thecolorapi.com/). Each color is shown as a swatch, and clicking a hex code copies it to your clipboard.

## Use it

Open `index.html` in a browser. No install or API key is needed.

## Files

```
index.html   Page layout and the color and scheme controls
index.css    Styles, including the small-screen layout
index.js     Calls the API, draws the swatches, and handles copying
```

If the API cannot be reached, the page shows a short message instead of an empty palette.
